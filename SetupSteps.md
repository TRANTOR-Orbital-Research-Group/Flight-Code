## Setup 
This is just what I did to get this all setup for running.
Keep in mind that I am on NixOS (Linux) and so the setup might not be exactly the same for someone on Windows.


First, I installed Pico tool and probe-rs. Note that I don't think we will likely be using probe-rs right now, but we might in the future.

Then I cloned the Pico-sdk, but it is already in the repo, so you don't need to do that again.

Now, we need to build the pico-sdk and the picotool SDK. You shouldn't need to do that either, though, because I already have.
